游戏下载路径（gamebanana.com.json）

网页设置读取 gamebanana.com.json：游戏名 + 香蕉网 id + 下载目录路径根目录；下载时自动找到游戏对应映射文件（mapping/<游戏名>.json）计算下载路径。📂 按钮 = 读取本地选择目录

➕ 添加游戏（输入香蕉网 id，游戏名自动获取）

默认下载位置

未在下方配置下载路径的游戏，下载时自动落到该根目录/游戏名文件夹（下载时自动创建游戏名目录）。留空则不启用默认位置（未配置的游戏下载会报错提示）。

🔀 文件夹合并（按映射重命名角色目录）

根据映射将文件夹重命名为「英文 – 中文」；同角色已有规范目录时内容并入，空目录进根目录 .trash（可恢复）

🧹 清空空文件夹（空壳 / 仅含 HTML）

➕ 手动添加角色映射

HTML 反查

输入文件 hash（md5）或图片原始短名（GB 原名），反查它属于哪个 mod。三索引：GB 信息表（hash → 线上 mod 信息）+ 本地表（hash → 实际下载位置）+ HTML 表（GB 原名短名 → mod，扫描全部 description.html）。
