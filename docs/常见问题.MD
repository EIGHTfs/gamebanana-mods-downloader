# 常见问题

> 使用类与维护类的常见问答（凭证、队列、长会话、截图重新生成等）。

## 使用类

**Q：未设置密码能直接用吗？**
A：可以，启动只警告。但局域网内任何人可访问，建议 `./start.sh --set-password "密码"`。

**Q：下载的 mod 在哪？**
A：在 `json/gamebanana.com.json` 里该游戏 `downloadPath` 之下，按「仓库 / 角色（英文 – 中文）/ [作者] / mod 名」存放。

**Q：重复文件会删吗？**
A：不会删。整理时重复文件与目录统一移入游戏根目录 `.trash`，可找回。

**Q：NSFW 或需登录的 mod 下不了？**
A：在「设置」填入浏览器登录 gamebanana.com 后的完整 Cookie（`sess=…; rmc=…`），点「检测登录状态」验证。

**Q：Cookie 明明有效，为什么「检测登录状态」显示未登录？**
A：GameBanana 会话绑定了**登录时浏览器的完整 User-Agent**（含 OS 与浏览器版本）。必须从登录 GB 的那个浏览器打开设置页保存 Cookie——保存时会同步该浏览器的 UA；换一个浏览器保存会因 UA 不匹配导致检测失败。

**Q：导入任务会不会把现有队列清掉？**
A：不会。导入 = 纯追加；只有点「终止」才清空队列（终止后导入 = 新建任务）。细节见 [数据格式与下载流程](数据格式与下载流程.MD)。

**Q：登录太频繁 / 每次都要输密码？**
A：登录页默认勾选「记住此设备」，勾选后签发 30 天长会话（cookie 与 session 同步失效），期间免登录；不勾选按默认 `sessionHours`（72 小时）。长会话时长可在 `server/config.json` 的 `sessionRememberHours` 调整。

**Q：下载时图片和压缩包哪个先下？**
A：图片 / gif 优先，压缩包后下；同一 mod 的全部项仍属同一分组，整组完成后才从列表移除（可在设置页 `taskListRemoval` 改为每个文件完成即移除）。

## 维护类

**Q：README 里的界面截图怎么重新生成？**

浅色 / 夜间主题逐页截图（自动登录、切换主题、收集前端错误）：

```bash
node scripts/page-shot.mjs --password <访问密码> --theme dark
```

进度页配图用固化脚本（元素选择固定，避免漏掉文件名；敏感信息自动打码）：

```bash
GB_BASE=http://<本机IP>:8642 GB_PWD=<访问密码> bash scripts/shot-progress.sh
```

README 里的截图用相对路径引用（`docs/screenshots/*.jpg`）。如果所在网络访问 GitHub 图片域名困难，可改用 CDN 形式（`cdn.jsdelivr.net/gh/<owner>/<repo>@main/docs/screenshots/…`）——两种写法二选一，别混用。

**Q：索引存储用 SQLite 还是 JSONL？**

默认 JSONL，旧 `.json` 仍可读。SQLite 后端代码保留但不启用，可用 `GBMD_INDEX_BACKEND=sqlite` 试用；迁移与校验脚本默认预演，加 `--apply` 才写盘。对比与回退原因见 [索引存储技术文档](索引存储技术文档.MD)。
